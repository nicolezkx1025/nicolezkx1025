## 1. 退化条件下的可信度

传感器退化、分布漂移、输入越界之后,**状态估计与策略还值不值得信**。三个切口:

- **不确定性量化** —— 把「有多不确定」变成可用的信号,而不是一句形容词
- **失效识别** —— 该说「我不知道」的时候,不给一个看起来正常的输出
- **降级与回滚** —— 不可信时,系统如何退到一个安全的档位

## 2. 从感知到决策的闭环

把状态估计、在线自适应与动作接成**一条可信链路**:世界模型负责预测,持续内部状态负责跨时间一致性,
在线自适应负责漂移,端到端集成负责让这些真的跑在同一个系统里。

## 3. 智能体的工程闭环

数据 → 训练 → 评测 → 部署,让能力**按轮次累积**,而不是靠一次性调参:Agent 的反思与纠错、
多轮对齐、评测闭环与数据飞轮。**这一条是我工程经验最厚的部分。**

## 4. 训练与推理基础设施

训练／推理链路的工程实现与优化:分布式训练、推理加速、并发与延迟。
**很多「模型不行」的问题,实际上卡在这一层。**

## 三个可复现实验

| 仓库 | 一句话 | 关键结论 |
|---|---|---|
| [**uq-state-estimation**](https://github.com/nicolezkx1025/uq-state-estimation) | 传感器退化下,状态估计的不确定性还可不可信 | 正常条件下两个滤波器无法区分;雾天时朴素滤波器声称 95% 置信区间、实际只兑现 **34.7%**;最难场景下精度与诚实不可兼得 |
| [**table-structure-gnn**](https://github.com/nicolezkx1025/table-structure-gnn) | 无边框复杂表格的行列结构与合并表头复原 | 边级准确率 **99.1%** 时结构 F1 只有 **0.551**,输给一条几何规则;**一致性后处理**把列分组 F1 提到 **0.695** |
| [**rag-eval-abstention**](https://github.com/nicolezkx1025/rag-eval-abstention) | 让 RAG 学会说「我不知道」 | 不拒答时精确率 **0.633**、幻觉率 **0.367**;阈值 τ=0.30 处拒答 18% 的查询后,精确率升到 **0.755**、幻觉率降到 **0.200** |

三个仓库回答的是同一个问题的三种形态:**系统如何知道自己什么时候不可信,并据此降级、保守化或拒答。**

全部**只用 numpy**,`pip install -r requirements.txt` 之后一条命令跑通,并明确写出局限与失败结果。
